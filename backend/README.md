# Murmur AI

Free, CPU-only inference server for Murmur. No paid inference API, account or key is required for app users. Hosting requires the developer's own server or free Hugging Face CPU Space.

```sh
python -m venv /workspace/murmur-ai-venv
/workspace/murmur-ai-venv/bin/pip install -r backend/requirements-dev.lock
cd backend
/workspace/murmur-ai-venv/bin/python models.py
MURMUR_ORIGINS=http://127.0.0.1:4173 /workspace/murmur-ai-venv/bin/uvicorn service:app --host 0.0.0.0 --port 7860 --no-access-log
```

Models download lazily or with `models.py`, from fixed revisions over TLS with verified hashes. Approximately 5.3 GB of models and several GB of RAM are needed. Whisper small int8 is the CPU default; it is not Whisper large v3 and is not claimed to provide its accuracy. Free CPU hosting can be slow, sleep or lose its ephemeral disk. No uptime guarantee. No physical iPhone/Safari hardware validation is implied.

The API accepts original audio up to 50 MiB and 60 minutes, uploads in 2 MiB resumable parts, persists each completed transcription block and anonymous voice prototypes in SQLite, and continues after client disconnects. The browser retains original audio and checkpoints. If the server loses its disk, the browser can reupload the original and continue from its saved position/prototypes. Server audio and job data expire after 24 hours. DELETE removes the job's stored files; an already running model call can finish its current in-memory block before stopping. Do not log job tokens or payloads. Tokens are opaque bearer capabilities, never put in shared URLs.

Speaker grouping uses neural pyannote turn segmentation, WeSpeaker VoxCeleb CAM++ LM voice embeddings and clustering, with Whisper word timestamps. It does not identify real people; short/noisy speech, similar voices and simultaneous speakers can be wrong. Uncertain groups are flagged for review; manual renaming/splitting remains available.

Insights are genuinely generated by Qwen2.5-7B-Instruct. Every retained claim and task must cite an existing segment and an exact supporting quote. Unsupported names/deadlines are cleared; relative deadlines are never silently converted. Exact quotes verify provenance, not the semantic truth of the generated interpretation. Review suggestions before use. Long transcripts are analyzed in chunks covering the whole transcript. No external paid service or data transfer by the models.

Default CORS origin: `https://treemonsal.github.io`; set comma-separated `MURMUR_ORIGINS` for other clients. Set `MURMUR_DATA_DIR` to a persistent mounted volume when available; free Space disk is ephemeral. `MURMUR_MODEL_DIR` configures the model cache. One inference worker, bounded 12-job queue and request/audio limits keep the free CPU service bounded. Public deployments have no account-based access control; use a private deployment or add gateway authentication before handling workloads that require it. Device/browser and host administrators can access stored data.

Models retain their upstream licenses: OpenAI Whisper (MIT), Alibaba WeSpeaker VoxCeleb CAM++ LM (Apache-2.0), Qwen2.5-7B-Instruct (Apache-2.0). Original speaker model is from the official k2-fsa/sherpa-onnx speaker-recongition-models release; its SHA-256 is fixed in speaker-model.json.
